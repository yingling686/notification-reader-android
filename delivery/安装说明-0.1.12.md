# 听讯 0.1.12 安装说明

覆盖安装“听讯-0.1.12.apk”，不要卸载，保留原配置。

本版修复一加/OPPO 系统引擎将中文标为 chn 时，被听讯误判成没有中文语音包的问题。

1. 设置 → 声音与语速 → 刷新已下载的系统声音。
2. 在“系统离线中文声音”中选择明朗男声、清冷女声或温柔女声，或保留默认。
3. 连接耳机，回首页点击“开启听读”，再到声音页试听。
4. 试听成功后，在“播报记录与待播”确认补读旧消息；发送一条新的微信测试自动朗读。

如仍失败，点“诊断与设备 → 复制精简诊断”发送完整文本。先确认 version=0.1.12；预期该引擎的 chineseCount 和 offlineChineseCount 能识别到 3 个。实际数量以引擎当时返回为准。

仍只使用标记为无需联网的系统声音，不改变 AI 配置和授权。朋友手机的实际合成与耳机出声仍需复测。
