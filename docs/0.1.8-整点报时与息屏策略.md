# 听讯 0.1.8 · 整点报时与息屏策略

版本 0.1.8 / versionCode 9；包名 cn.tingxun.app；compile/targetSdk 36，最低 Android 11。沿用原签名、极简首页、俱乐部品牌和现有 MiniMax/OpenAI 配置。

## 行为

两个新开关默认关闭，升级旧配置时也默认关闭；进入设置页面不保存配置或取消播报。

**整点报时**仅在已开启、未暂停的听读会话中运行。开启从下一个整点开始，使用当前声音；AI 语音计入原语音请求额度，不调用摘要。中文采用 24 小时报时，例如“现在是十六点整”。固定试听明确标为十五点示例，复用同一合成与耳机安全检查路径。

会话计时与 AlarmManager 共用持久化小时标记，在派发前去重。暂停、停止取消闹钟；恢复、重新开启、修改配置不补报旧小时。整点第一分钟以外、无耳机、通话、免打扰、亮屏限制等条件下跳过，不积压旧报时。不打断正在播放的通知；排到报时前已过有效窗口也跳过。

API 31 起可由用户在系统允许精确闹钟；权限撤销的竞争情况回退为非精确闹钟。没有授权时仍保留会话计时和系统非精确唤醒，不能承诺准时。接收器只服务现有会话，不在应用未开启时创建后台听读服务。实现参照 [Android 闹钟说明](https://developer.android.com/develop/background-work/services/alarms) 与 [AlarmManager](https://developer.android.com/reference/android/app/AlarmManager)。

**仅息屏时播报**共用播放门槛，覆盖通知、摘要、报时及试听。亮屏新通知保留待播，不因这一门槛转为手动补读；息屏事件直接唤起自动调度，内容模式与定时间隔继续生效。亮屏中断正在合成/播放的任务会取消并使迟到结果失效，批次保留自动待播状态，已完成段落通过游标排除；未完成当前段可能重播。主动暂停、清空、断连、通话及免打扰仍优先遵守原安全中断规则。

未新增全天唤醒锁、静音音轨或麦克风采集。实际耳机路由仍需确认才发声。匿名诊断新增整点到期、完成、跳过和原生闹钟接收阶段，以及两个开关的运行快照，不记录通知正文或密钥。
