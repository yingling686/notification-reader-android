# 听讯 0.1.9 · 整点通知回顾

versionCode 10，沿用原签名，数据库结构不变。设置 → 整点报时增加独立开关“AI 总结上一小时通知”，默认关闭，旧版本配置缺少该字段时也关闭。原有整点报时和仅息屏设置保留。

开关开启需先配置并主动授权 AI 摘要；它不代替语音授权。需同时打开整点报时、开启听读会话，遵守耳机路由、通话、暂停、免打扰和仅息屏限制。关闭时沿用纯报时；开启后使用现有 MiniMax / OpenAI 兼容摘要接口与当前声音。

例如 16 点触发，检索通知接收时间在本地 15:00:00（含）到 16:00:00（不含）的记录。按预定整点计算范围，延迟回调不会挪动时间窗；跨午夜和夏令时按该整点之前经过的 60 分钟处理。只查询当前选中应用，包含已播、未播及此前判为不重要的通知；不含已清空/跳过、失败和待确认补读的记录。不接触其他应用数据，不补抓未开启听读时的通知。

独立回顾不改变原通知、批次状态或游标，也不释放积压。即时模式仍可听到整点回顾，这是有意的复盘；该功能默认关闭。通知资料继续适用既有防提示注入与思考内容过滤。

每次最多取最近 50 条、总输入 12,000 字符（含提示前缀），按接收顺序交给模型。超量且有摘要时，明确朗读“以下仅概括最近部分通知”，避免声称覆盖全部。每个有资料的整点最多自动请求一次，计入每日摘要额度；无资料不请求。无重要内容或空正文只读时间。网络错误、35 秒超时或额度耗尽也回退纯报时；鉴权失败会暂停后续自动摘要，用户需修复配置/测试。报时仍遵守原整点第一分钟窗口，来不及合成时不播过期内容。

所有合成和播放共用原任务代次与取消路径。关闭开关、撤销授权、清空、暂停、断连或亮屏限制生效后，旧结果不能继续播放；不加入自动补报。没有启用新云端授权或变更原接口/密钥。

单元测试新增时间窗、容量、顺序、范围提示、空正文和思考内容过滤；Android 用例新增数据库范围及状态过滤、开关持久化、关闭时无请求、开启时摘要、空资料/无重要内容/失败回退，以及清空/撤销授权后迟到结果取消。最终运行结果见 delivery/测试记录-0.1.9.md。
