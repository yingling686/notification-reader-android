# 听讯 0.1.7 · 极简首页与俱乐部品牌

日期：2026-10-19。版本：0.1.7 / versionCode 8。包名 cn.tingxun.app；compile/targetSdk 36，Android 11 起支持。

## 已实现

- 首页改为米白背景、深青绿圆形声纹、会话状态、耳机信息、只读模式/引擎摘要与一个大按钮；取消底部分页。
- 未开启时按钮开启，等待/合成/播放时暂停，用户暂停后恢复；受阻时保留会话，按钮进入对应处理页面。权限、未选应用、耳机、通话、免打扰与处理异常分别说明原因。
- 等待/暂停/受阻时声纹静态，合成时脉动，播放时变化。仅表达应用状态，不采集麦克风。
- 右上角齿轮进入设置目录：应用与规则、内容与定时、声音与语速、AI 服务配置、免打扰、记录与待播、会话控制、权限与后台、诊断与设备、隐私与数据、关于。
- 摘要与语音保留独立的 MiniMax/OpenAI 配置、密钥、授权、测试与用量。AI 声音仍需授权、密钥及语音测试通过。
- 现在播报、跳过、补读、清空移入记录与待播；停止会话移入会话控制。清空、删除及云端授权确认仍保留。
- 导航使用可恢复页面标识与明确父级，系统返回和标题返回逐级返回；打开页面不保存配置。导航、Activity 重建不会主动暂停或重启听读。
- 首页展示透明俱乐部图案与“接化发俱乐部出品”，关于页展示用户完整 Logo。完整 Logo 与输入文件哈希相同；用户原文件未修改，桌面图标仍为听讯。
- 六张宣传图均添加俱乐部标志与出品文字，第 5 张根据实际 0.1.7 首页更新界面示意。原套图保留，新图保存至 marketing/个人形象版-俱乐部品牌版。

## 安装与复验

直接覆盖安装 delivery/听讯-0.1.7.apk，不卸载旧版本。安装后回首页开启听读；原配置无需重填。
有问题先检查首页具体原因；权限与后台限制从设置对应入口处理，后台诊断从“诊断与设备”复制。
实机复验：开启后回桌面、切换应用、锁屏静置后发全新通知，首次通知前不点媒体播放或试听；再验证连续通知及耳机断开停播。人耳实际听到和未外放需由实机确认。

源码交付包不含签名私钥、signing.properties、local.properties、缓存、原始人物照片或用户运行数据；本机原签名配置保留。宣传图使用内置 imagegen 编辑，完整提示词随图交付，未发布。
