## 实机操作清单

1. 安装 release APK；开启通知访问、发送通知与电话状态权限，选择微信。
2. 连接蓝牙耳机，开启会话，先以系统机读完成试听和即时通知测试。
3. 从另一设备发送单聊、群聊和连续消息，检查没有重复读历史消息。
4. 播放中断开蓝牙，确认停播且无可听外放；重新连接后确认不会自动补读旧内容。
5. 设置 1 分钟定时朗读，检查多条消息合并与已播内容排除；再测试锁屏延迟。
6. 分别授权并测试 MiniMax 摘要和语音，验证四种模式搭配两种声音；确认思考内容不进入播报。
7. 添加联系人规则，检查命中消息即时读、其他消息定时摘要，以及无重要内容时安静。
8. 在云端请求期间暂停、撤销授权、清空队列，确认迟到结果不会播出。
9. 测试通话、音乐、免打扰、跳过本次、手动补读及删除全部数据。

## 已知边界

- 系统、微信或 Android 敏感通知保护隐藏的内容不可读取。
- A2DP 音箱、车载设备与耳机可能具有同一设备类型，请在确认的耳机上开启会话。
- 输出设备检查和断连回调仍有系统时序边界，不能宣称所有设备绝无瞬间外放；实机验收是必要条件。
- 不读取耳机佩戴传感器；“连接耳机”不等于“实际戴在耳朵上”。
- 系统 TTS 仅选取引擎标记为离线的中文声音，缺少语音包会提示并保留队列。
- 未播完的一段补读时从该段开头重读；已完成段落通过持久化游标避免重复。
- 清理在应用启动与会话运行期间执行；进程停止期间无法准点执行24小时物理清理。
- 目前没有商店上架、自动重启会话或云端账号后台。
